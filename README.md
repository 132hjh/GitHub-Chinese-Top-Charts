# GitHub 中文排行榜

GitHub 中文排行榜用于发现优秀的中文开源项目，帮助中文开发者按技术方向和项目类型高效浏览、学习和收藏项目。

## 项目特色

- 汇总中文 GitHub 项目
- 按编程语言分类
- 区分软件类项目和资料类项目
- 提供中文总榜、增速榜和新秀榜
- 按项目发展阶段帮助读者发现值得关注的仓库

## 榜单分类

当前内容主要包括：

- 中文总榜
- 中文增速榜
- 中文新秀榜
- 软件类项目
- 资料类项目

支持的技术方向包括 JavaScript、Java、Python、Go、TypeScript、Vue、C++、C、C#、PHP、HTML、CSS、Rust、Jupyter Notebook、Ruby、Lua、MATLAB、R 等。

## 使用方式

本项目是一个以 Markdown 内容为主的静态排行榜资料库：

1. 打开对应榜单分类。
2. 按编程语言进入相应页面。
3. 根据项目介绍、热度和更新趋势选择感兴趣的仓库。
4. 收藏或访问原项目继续学习。

## 项目状态

项目包含完整的榜单目录、分类页面、说明文档和许可证。仓库中的榜单数据需要持续更新，历史数据不代表当前 GitHub 排名。
